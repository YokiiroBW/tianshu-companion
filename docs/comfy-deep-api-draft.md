# ComfyUI deep integration API implementation (2026-10-05)

The proposal was frozen into the coordinator's `contracts/image-backend/v1` and `contracts/life-runtime/v2` at root commit `725113bcc5676972226d0c73ae2543cdc8495085`. These published schemas are authoritative; this document describes their Companion implementation.

Keep existing `/internal/v2/life/manage` `image.backend.configure` and read `image_backend` compatible. Add three authenticated Companion endpoints reusing the same dispatch, registered Platform caller and existing actor management authority, with no new permission registry. All requests require `schema_version:1`, `request_id`, `actor_id`; only the trusted `platform` caller can invoke them. Model tools continue using existing `image.request` and cannot configure URLs, graphs, credentials or bindings.

- POST `/internal/v1/image-backend/read`: `resource` is `status`, `workflows`, `workflow`, `actor`; `workflow_id` is null or the discovered ComfyUI userdata path relative to `workflows/`. Read `workflow` returns inspection and inferred bindings, without saving or submitting a prompt. Discovery uses GET `/userdata?dir=workflows&recurse=true&split=false` and GET `/userdata/{percent-encoded workflows/path}`; if unsupported return the real dependency failure. No remote filesystem path or model-provided URL.
- POST `/internal/v1/image-backend/manage`: `operation` + `expected_version` + `value`. `connection.configure` value `{base_url,credential_ref,enabled}` uses global connection CAS (`status.version`, initially 1). All other operations use per-actor CAS (`actor.version`, initially 1). `workflow.select` value `{workflow_id,bindings:null|object}` selects, converts, validates and freezes this actor's discovered graph, leaving original source untouched. `bindings.update` value `{bindings:object}` adjusts the current frozen selection. `actor.configure` value `{workflow_id:null|string,character_prompt:string,defaults:object}` gives this actor a workflow and optional explicit stable identity; empty identity retains the graph's fixed character. Defaults contain optional semantic text and `width,height,seed,steps`. Selection is metadata, not a second job ledger.
- `workflow.analyze` value `{workflow_id:null|string,goal:string,assist_model:boolean}` is read-only. With no id, model assistance selects an exact id from the actual discovered directory, then inspects only that graph and may recommend exact typed candidate bindings. It never writes the connection, credentials or graph. Returns the inspection with `candidates`, `model_receipt` and `selection_reason`. Both model calls share a 120-second deadline.
- POST `/internal/v1/image-backend/compile`: `intent:{character?,outfit?,pose?,background?,camera?,positive?,negative?}`, `parameters:{width?,height?,seed?,steps?}`, `assist_model:boolean`. Uses actor selection or existing standard configuration fallback. No upload or POST `/prompt`, even with model assistance. Returns exact compiled graph and readable changes, stable protected-node evidence, workflow hash, translated semantic prompts, dimensions and optional model receipt. Compilation and actual image.request share the compiler. Width/height are 64–4096, steps 1–150, and the existing 4,194,304-pixel budget applies. Dimensions add plain horizontal/vertical/square canvas text to the camera prompt.

All responses `{schema_version:1,request_id,actor_id,result:object}`. Faults use existing closed Fault wire. `read` status result `{id,version,state,provider:"comfyui",base_url,credential_ref,enabled,workflow_id,workflow_version,checked_at,error_code,capabilities:{discovery,model_assistance,structured_prompt,reference},models}`. state `not_configured|disabled|configured|unreachable|workflow_required|unsupported` is truthful. No credential token in any projection.

`workflows` result `{items:[{id,name,source:"comfyui_userdata"}],source:"comfyui_userdata"}` excludes explicit backup directories and non-JSON files. `workflow` result `{workflow_id,workflow_version,format:"api|ui",state:"ready|unsupported",nodes:[{node_id,class_type,title,inputs:[{name,type,value,linked}]}],bindings:object,candidates:object,unresolved:[{code,node_id,detail}],protected_nodes:[{node_id,class_type}],outputs:[node_id],conversion:{strategy,evidence},model_receipt,selection_reason}`. Inspection's version hashes the source; actor/compile versions hash the frozen API graph, bindings and outputs.

`actor` result `{id,actor_id,version,state,workflow_id,workflow_version,character_prompt,defaults,bindings}`. Workflow selections are per actor; changing one actor does not select a workflow for another actor.

Binding keys `character,outfit,pose,background,camera,positive,negative,width,height,seed,steps,reference,reference2,reference3`. Each `{node,class_type,input,mode:"replace|append",min?:integer,max?:integer}`. Auto infer semantic selector classes and connected prompt inputs, CLIP polarity by sampler links, linked ResolutionMaster, actual sampler and LoadImage. Multiple candidates remain unresolved and editable in UI. `mode` protects style prefixes (positive append default); Anima fixed quality/artist/LoRA are never auto mapped. Numeric constraints come from live object_info and bounded product limits.

UI conversion is node-aware, not widgets zipped to required inputs: explicit known serialization adapters for KSampler (seed control widget), Anima selectors/composer, ResolutionMaster custom widget order, standard loaders/encode/decode/save and Simple String/Prompt Router. Named-widget maps supported after live type validation. Unknown list-widget layouts, bypass/subgraphs or unresolved links return unsupported and require API-format export. Live object_info validates node availability, input scalar types/enums/required links and output slots.

Compile result `{state:"ready",provider:"comfyui",workflow_id,workflow_version,graph,graph_sha256,prompts,dimensions:{width,height},changes:[{semantic,node_id,input,before,after}],preserved_nodes:[node_id],warnings:[],model_receipt:null|object}`. Prompts is a string map of actual nonempty mapped semantic fields; absent character means graph identity was inherited. Model assistance uses the actor's existing selected generation config through Gateway; model output is only bounded dynamic semantic strings or an allowlisted existing binding target, never graph code/URL. Unconfigured model returns unavailable rather than inventing translation.

Actual execution retains existing image_jobs, prompt_id/submitted/unknown reconciliation, reference authority, staging, album and original image delivery. Existing standard_sd remains supported; no NAI or online provider implementation this round.

Existing `life-runtime/v2 image.request` accepts optional top-level `intent` and `assist_model`. For a configured actor, omitted assistance defaults to translation; explicit false keeps literal prompts. Fixed identity is excluded from translation. Compiled values, graph and model receipt are cached once per job before admission; an interrupted preparation returns unknown without charging again. A native tool caller reuses its already held model slot, while ordinary callers still use the existing semaphore.

The provider boundary has `submit(local_id,plan) -> ImageResult`, `poll(opaque_handle,plan)` and cancellation/result download operations. Submission returns an opaque handle and may already be completed; handles persist in the original image_jobs ledger before downloading. Comfy queue/history/state mapping stays in its adapter. Synthetic synchronous and server-assigned asynchronous providers verify this extension point without implementing another vendor.

Proactive expression may decide on a structured photo intent. The original sourced candidate waits on a stable Images job, then sends that exact original through its original delivery queue after subscription/source validation. Failed generation cancels the candidate; completion does not create another photo or another motive for the same subscription. There is no synthetic conversation turn.
