## 变更

- `astrbot_plugin_tianshu/` 可作为独立 AstrBot 插件放进 `data/plugins/`。默认关闭，配置需独立连接 Bearer、aiocqhttp 平台实例 ID、机器人 QQ self_id、精确外部会话白名单；默认仅接管 `天枢 ` 前缀的纯文本，其他消息照常传播。可显式启用专用会话全普通文本模式；`/` 指令始终放行。插件不做模型推理、记忆、来源签发或角色授权。
- 用 v4.27.3 官方事件实现核对原生 OneBot 事件的 `post_type/message_type/message_id/time/self_id/user_id/group_id/message`，拒绝媒体、引用及混合段。该版本 `message_obj.timestamp` 是转换时间，故取 SDK 原始 `time`；同时核对 AstrBot getter 和原消息 ID。平台 events 请求带 `schema_version/platform_id/self_id/revision`，外部会话键为 `group:<id>` / `private:<id>`。
- 插件数据目录 SQLite WAL 先持久化入站摘要与出站发送意图；入站重复或语义冲突不重交，结果不明只查询 `events/status`。平台 reply claim 一次领取一条，发送前落 intent；崩溃/超时/缺原生消息 ID 一律 unknown 且不重发。原 aiocqhttp `send_group_msg/send_private_msg` 返回数字 `message_id` 后才 ACK sent；ACK 丢失只重放同 attempt 的持久回执。
- `PlatformHTTP` 默认使用系统 TLS 信任库，也可按连接配置只读挂载的 `ca_file` PEM；始终校验证书链和主机名，同时禁重定向、限制固定路由及响应大小。令牌、原文及异常体不进入日志；仅输出节流的固定状态码。连接撤销以后平台会拒绝新事件和领取。
