- 连接专属 Bearer 仅访问平台机器人 HTTP 端点；内部地址使用 HTTPS 并验证 CA/主机名，只有 loopback HTTP 供本地测试。SQLite/WAL 本地 journal 在 HTTP 入站和原生 SDK 发送前持久化意图。相同事件去重，断线后入站 unknown 只查状态；回复 unknown 只补 ACK，不重发 SDK。仅真实 OneBot `message_id` 可生成 sent 回执。
- Core 增加显式 `bot_platform_bindings` 选择：选中的平台 QQ/TG binding 走 `platform_sender`，未选中的原 qq/tg 仍走旧 `nonebot` sender。平台回复状态查询只读，按原请求验证回执。示例配置、精确依赖与安装/权限/CA 说明见 `integrations/nonebot/README.md`。
