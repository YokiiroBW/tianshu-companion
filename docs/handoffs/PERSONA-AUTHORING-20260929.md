## 目标与变更

- `Personas.manage` 增加档案目录/详情、创建、保存、应用和已登记角色直接编辑/应用操作。
  可复用档案使用同一 Personas 修订存储和生成 ID，不加入角色登记，Core 不接受其作为对话角色。
- 名称、简介只作为目录元数据；四个表单字段写入人格正文。对旧修订未在表单展示的扩展字段做覆盖式合并，
  复制也在服务端读取指定版本，保留扩展字段。
- 保存草稿不移动角色发布指针。应用在一个 SQLite 事务内创建修订、批准、发布并记录幂等操作；
  档案与目标角色均检查乐观版本。失败回滚整个操作。
- 应用档案时只继承目标角色的非编辑扩展字段，四个编辑字段完全以档案为准，留空可选字段会清除。
  Core 从钉住快照的 `content` 将非空语气、风格、称呼连同正文组成模型 system 文本；
  只有正文的旧角色保持原 system 文本。名称/简介不进入提示词。
- 档案记录其上次应用产生的目标发布修订，供网页与目标当前指针核对应用状态。
- 部署导入仍不覆盖已发布角色；新增档案不会扩大来源、机器人白名单或发送权限。
