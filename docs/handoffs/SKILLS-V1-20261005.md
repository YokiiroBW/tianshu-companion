`skills/registry.py` 统一拥有技能定义、安装 handler、角色启停/配置和来源目录。Core 原有 native 循环只读取该目录和工具，不再持有生图专用提示。生图的 compact 参数、真实当前穿搭、固定身份与表达说明位于 `skills/image.py`，仍回到 LifeRuntime/Images 的原账本和原图投递。原 life/read/content/memory 工具沿原领域实现注册，模型继续自动选择。小规模目录直接提供当前可执行操作；未配置、停用和无 adapter 的目录项不提供可执行工具。

技能更新、启停、来源配置/刷新走 `POST /internal/v1/skills/read|manage`，复用 Platform 服务鉴权和既有操作重放，角色 CAS 初始版本为 1。已发布 `skills/v1` manifest pin 为 `0ad3a444e8bff26721c14664260d08b463feb3288a556364e1af35f3e277d0f2`。已创建的领域任务仍照常完成/通知；技能停用只影响 AI/主动新调用，管理员直接领域管理继续沿原接口。

每个 turn 固定工具名到技能 owner 的映射，只核该技能的有效 revision。定义/配置/启停和来源启停参与该 revision，无关技能变更及刷新时间不参与。生图还核实际继承的 global Comfy 连接与角色 workflow，异步转译后、任务落账前再次检查。来源只能原子替换自己的条目，不能覆盖 builtin/local/其它 source；失败保留旧目录，删除停止新调用，新条目默认停用。聚合合同投影在事务提交前验证，超限回滚。远程仅提供有界 JSON 元数据，不安装/导入代码；schema/操作集合由已安装 handler 拥有。公开 options 只走 handler 白名单，目录和模型上下文不带凭据引用或秘密 URL；令牌通过既有 credential resolve，使用 `companion.skills` 和固定 URL origin，禁止重定向跨源复用。

新增 adapter 可向同一 registry 注册 definition 和 handler，无需修改 Core。Handler 提供 `domain`、`operations`（语义操作到工具名）、配置校验、公开 options、availability、工具 schema、上下文/领域说明和 execute；需要时提供 normalize、revision_context。操作必须属于该 handler 已安装集合，原有 scope/来源/投递规则继续由领域执行器负责。媒体视频/图片/漫画、网页搜索和订阅扩展目前无安装 adapter，明确 `unsupported`，没有下载或查询假成功。

GSCore 首版 handler 为 `gscore.query`、技能为 `game.guides`，配置为 provider `gscore`、URL、现有凭据引用与空 options。它只接已核实 `POST /api/send_msg` HTTP 协议，使用独立服务身份和七条有版本数据映射：鸣潮攻略/矩阵队伍统计、异环攻略/配队、终末地攻略、星铁攻略、绝区零攻略。模型只给 game/operation/character，没有 raw_command、shell、MCP、WS 或第二层推理兜底。鸣潮统计不能冒称个性化配队求解。

该 GSCore 实机的 HTTP/AI/MCP 开关未开启，且源码 HTTP Bot 未启动队列消费者；首次 send 并非 handler 终态、多段输出可能覆盖。因此这里交付 HTTP adapter 与协议替身，**不声称真实联通**。配置存在仅表示可尝试，`http_configured_network_unverified` 明确不等于探测通过。每个 turn 的相同语义查询持久缓存一次，未知、超时、空产物和拒绝不自动重试；返回片段也保留 `state=unknown`、`complete=false`。实机需由 GSCore 拥有方以后修复服务端，再另行验收；本轮未修该服务。

返回 text/markdown 可读；base64 PNG 原件复用既有 staging/image_media 和当前 turn scope/原件读取/共享 sender，附真实查询来源。它不创建 image_jobs，不写日常相册/生活事件，不触发 image_complete。外部 target_id 只核调用关联，不能改变收件人。完整性未知和真实投递状态分别记录。`file://`、`link://`、其它图像格式或畸形图片给出 `unsupported_content`，不读取 NAS 路径、不下载任意 URL、不新增图像依赖。模型从图综合建议前必须用现有 `life_read(resource=image,id=content_ref.object_id)` 看原件；视觉不支持/超预算时如实说明。
