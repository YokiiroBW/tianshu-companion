2. 当前仅单进程 SQLite/WAL；有第二所有者拒绝保护。生产 PostgreSQL、多进程、数据库迁移与长时间负载尚未实现/验收，不能用于生产能力声明。
3. 回执查询没有冻结 wire，默认 reconcile 不可查；closed_unknown 保留历史不确定性，迟到事实写 reply/投影。网页 snapshot/SSE 尚未实现。
4. 缺权威 scope_version 的早期失败释放槽并保留本地 blocked_scope；需部署当前来源/修订/取消遗忘/范围核验器才能补成合法 outbox 事件，默认无修复器，不伪造已整理入库。
5. 群内首个授权角色负责回复；多目标保留但没有多角色分别生成。依赖识别为明确前轮方案短语的首版规则，不宣称通用语义依赖判断。当前无工具动作、日记、世界/小屋功能。
6. 核心保留媒体引用，薄桥尚无资产摄取时拒绝原生媒体；Chat Audit 未接，来源保持 pending。尚无 inbox 保留/清理流程，长期/高流量使用前需补此策略。
7. 预发送复核和远端权限更新没有跨服务原子性；发送只保证本地提交顺序，不能推导远端实际到达顺序。
