## 结果

`Memory.profiles` 真实序列化并消费 `/internal/v1/memory/profiles/select`，校验请求/响应关联、完整 requester_scope、target、unit.subject/category、完整依赖组、共享类型、有效期和保守预算。只允许合同中的投影来源；私密可见性、原文扩展字段、好感数值字段、错误版本域或缺组成员都会拒绝。

Core 对当前群查询 topic/style，对当前消息与获准近期完整群消息的稳定 person_id 查询 interest/style；请求人始终使用当前受信来源和自己的 scope。昵称和跨平台 username 不参与身份关联，未经核验的提及不触发其他账号的 resolve/register。目标只在有界当前窗口内发现，不枚举群成员或私人目录；无匹配不等于人物不存在。

群短期消息按完整作者组保留，显式提供 person_id 和不可变作者账号；同群其他人物、完整 observed 消息可参与。严格匹配角色、受众、渠道、线程与核心会话。其他作者用其原来源逐一核验绑定和文字版本；只读取有 sent 回执及渠道消息 ID 的回复，待发/发送中/unknown 文本不可见。旧私聊边界、两轮 prepare、有序发送、普通取消、来源编辑/撤回和续接检查保留。

附加语境共用 16 KiB canonical UTF-8 预算，包括普通记忆、画像、依赖组、短期消息/回复及显式续接/已发送依赖；tokens 为同字节数保守估计。每个画像目标最多请求 4096 与剩余额度的较小值。全部保留条件、否定、时间、不确定性和因果语义，不截句/拆组；整目标画像放不下则省略。必要续接或依赖本身超额明确失败，当前入站与人格另受原总上下文 512 KiB 限制。

发送每段前分别用两个版本域的零预算探针复核，整数相等也不能复用。持久化且传播旧回复依赖的画像/其他作者复核元数据，避免遗忘后通过衍生回复恢复旧画像；元数据去重后最多 64 条。源码修订使本机窗口失效；私人来源的共享画像撤销可仅通过画像版本变化停止待发部分。已发送账本保留真实事实。普通取消回复并不撤回那条已受理用户输入。

## 局限与下一步

- Memory 真实 SourceAuthority、生产发布批准策略/issuer、真实模型和 QQ/TG 仍未接通；本任务不是全 L0/L1、网络/TLS 或生产外部送达验收。生产授权过滤由 Memory 执行，Core 校验发布 wire 与受众边界；不能靠提示词代替发布批准。
- 群候选限定完整近期窗口；窗口外人物、未完成收集组和仅凭昵称提及不推断身份。画像相关性复用生产者词项/字段查询，不能保证所有自然语言问法命中。

- 不承诺发送与外部授权变更的分布式原子性。既有历史轮次缺新来源标记时不恢复 observed 语境；未增加数据库迁移或生产保留策略。
