## 风险与缺口（按卡如实记录）

1. **进程内并发**：`Store` 是 SQLite 单进程所有者，乐观并发由 `expected` CAS 在进程内保证；
   两个 OS 进程同时写同一库由 owner 锁整体拒绝（`service_running`）。跨进程并发编辑不在本轮范围。
2. **跨多版本升级只取一份恢复备份**：沿用产品既有备份语义（每次打开最多一份、标签取本次跳升
   的最高结构步骤），因此 v5→v8 只得到 `pre-persona-v8`。需要中间版本可恢复点时应分步升级。
   本轮**未修改**该既有语义；已在 `docs/personas.md` 与 `AGENTS.md` 写明。
3. **管理端口凭据缺失即不可用**（非"未配置也算成功"）：未设 `personas.admin_token_env`
   所指数值时不注册 `persona_admin`，路由 401/503。
4. **未做**：平台网页、新跨产品合同、真实模型费用、真实渠道发送、人格质量/语气保证、
   模型改写、人格评分。人格文本不是权限这一点由代码与测试共同保证，但不是安全审计结论。
5. **未验收**：本轮产出为提交 + handoff + 标准交付包，等待协调方审阅；不自行合并/推送/部署。
