## 行为与边界

- Health 的 runtime 项读取真实后台循环生命周期：首次成功前、失败、停止、退出或超过新鲜度窗口返回 failed。成功空轮次恢复健康，失败退避不被错误计数掩盖。
- JsonService 在累计响应前限制 2,000,000 字节；identity 协商并在解压前拒绝其他编码；查询和命令共用完整 15 秒请求预算，命令不自动重试。原路径是对端可控正文先完整 aread 后检查，修复位于全部消费者共用的传输边界，合法 JSON 和错误映射保留。
- 防抖集合保存首条输入 correlation_id，每条 inbox 另存各自 ingress ID；turn、处理、发送、重启后对账、outbox 均复用持久 ID。老 turn 缺 ID 时生成并持久保存。
- Outbox 每行记录真实 succeeded/failed/cancelled，失败保留 pending 和重试截止，不再把一次失败尝试报告成功。
- 工作会话按页扫描活跃索引，轮转保证后续会话可进入；每页最多 64 会话，未知回复每页 32，outbox 每页 64。历史 turns/outbox 不为判断空闲工作反复反序列化。收集上下文在索引中取最近 32 条。
