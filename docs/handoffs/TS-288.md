- `JsonService` 把原异常映射前的封闭类别、登记的 MRO 异常类型、peer/请求种类及已实际收到的 HTTP 状态透传为 `Fault.cause`；不读取异常文本、URL、header 或响应正文作诊断。`Fault.wire/status/unknown` 及重试判据不变。`Gateway.complete` 对实际请求的 stream 和整个完成/回执后处理边界统一附 `model_request_id`；请求体尚未通过校验时不假造已发起请求的 ID。
