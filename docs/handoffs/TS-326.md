- 共享 SDK 群规则确定迁移到 disabled / observe / reply / active，群/私消息在正文加工前核当前账号启用、租约与有效策略。真实 @ 与字面关键词分开；只有 active 进入 NoneBot 普通消息所有权 graph。AstrBot 无 ordinary claim 时诚实不可主动参与。三个共享模块与两个发布副本逐字同步，并已构建 ZIP/wheel。
- AL12 复用 MemoryLearning 单自动阶段、ModelSlots.background 和独立 companion_background Gateway/selector，function 为 participation。未解析作者保持 person_id=null，native 群上下文不是伪 Core CID。模型只作 engage/silent；原 Platform/SDK AL11 candidate、决定、claim/register 和原回复链负责地址、权限与发送。按实际开始判断合并同群候选，silent/unknown 也冷却，原 60 秒 TTL 不延长，unknown 不重模型。
- 当前 processing batch 是自动整理资格提示，沿真实 inbox native frame 或唯一 Core channel；新 native frame 随本地预算封段保留，无法唯一映射的旧 opaque 材料正常 pending/mapping_required。disabled 不耗 attempt、不造 blocked、不改历史 source/read_enabled/epoch/删除证明。已发操作与原 output/job/window 保留 receipt-first。完成 task 先清理再刷新，避免其他群连续工作令已启用群永远吃旧 paused hint。
- 状态端口只供已鉴权 Platform 纯读实际 consumer/BG 可用性，不 heartbeat 或触发业务。行为说明见 `docs/group-modes.md`。
