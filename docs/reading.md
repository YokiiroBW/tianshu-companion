# 书库目录与显式陪读

书籍事实归Platform管理，Companion通过既有Origins登记的服务连接读取 `reading-state/v1`；不读取媒体数据库或NAS文件。新增`book_reading`模块与既有Knowledge原件阅读的`reading`模块职责不同，后者保持不变。

普通私聊可取得与当前人物映射一致的书库目录。网页开启陪读后，所选角色能取得当前书、章节、Unicode码点位置及至多800字已读片段；角色/人物/来源、登录及心跳由Platform核验。群聊不请求私人书库。不能依据管理员会话、角色名字或相似账号自动认定同一人物。

材料加入用户上下文中的 `book_reading` 字段；系统仅说明资料来源和引用规则，不把正文嵌入系统指令。目录不表示已读，书中故事不作为用户现实经历。翻页不产生模型调用、消息或Memory写入。轮次仅保留授权检查标识，不持久保存实时章节片段。

捕获材料前复用现有来源检查，发送前再次验证所采用的共享会话。进度移动保持会话；关闭、过期、重开或换章/角色会使未发回复失效。普通聊天遇到未安装合同、旧平台无接口或读书服务故障可继续，但不会伪造正在阅读的信息。已采用陪读材料后核验失败则阻止该回复发送。

合同从协调仓库读取并校验固定manifest与文件摘要。部署需为Platform与Companion共同提供新合同目录；存在损坏合同会明确失败，旧部署缺少整包时保持普通聊天兼容。
